# Plan: Shrink the Monitour agent (5.5 GB dist → ~90–125 MB installer)

## Problem (measured)

`agent/dist/` is **5.5 GB**, but the real tsc output (`agent/dist/main/`) is only **350 KB**. Everything else is electron-builder output — inflated by a config bug that recursively packs old installers into new ones:

| Item in `agent/dist/` | Size | Cause |
|---|---|---|
| `Monitour Agent Setup 0.2.2.exe` | 1.8 GB | embeds the two previous installers |
| `Monitour Agent Setup 0.2.0.exe` / `0.2.1.exe` | 874 MB / 583 MB | stale artifacts |
| `win-unpacked/` | 2.4 GB | staging dir; `app.asar.unpacked/dist/` = 1.5 GB of old installers + `app-builder-bin` 207 MB |
| `main/` (actual tsc output) | 350 KB | — |

### Root causes

1. **Output-dir collision + recursive self-packaging (dominant bug).** `agent/tsconfig.json` `outDir: ./dist` == `electron-builder.yml` `directories.output: dist`, and `files: [dist/**, …]` packs it. Each build embeds all previous installers (874 MB → 583 MB → 1.8 GB, exponential). Confirmed inside `app.asar`: old setup exes + a whole prior `win-unpacked/` Electron build.
2. **`app-builder-bin` in `dependencies`** — electron-builder's internal helper (207 MB unpacked), never imported by agent code. Ships into the app.
3. **`files: node_modules/**`** packs the entire hoisted **root** `node_modules` (893 MB) — all workspaces' deps (vite/react/mongoose/typescript…), jimp/@jimp ×479 files, node-pty C++ sources + .pdb debug symbols, libnut for all 3 OSes.
4. **tsc emits `*.map`, `*.d.ts`, `*.d.ts.map`** (`tsconfig.base.json`) — packed into the app.
5. **`asarUnpack: **/*.exe, **/*.dll, **/*.pdb`** — flings everything (incl. old installers today) out of asar, uncompressed.

## Goal (confirmed with user)

- **Phase A**: fix the packaging bugs (low risk, quick win → ~110–160 MB installer).
- **Phase B**: dependency diet + bundling + per-platform pruning (→ **~85–125 MB**). Stay on Electron.
- Keep all 3 targets: Windows x64 (NSIS), macOS x64+arm64 (DMG), Linux x64 (AppImage). All features preserved (streaming, thumbnails, input incl. locked-desktop koffi path, terminal, file transfer, enrollment, NSIS self-update).

**Honest floor**: Electron 45 runtime is 357 MB uncompressed (~90–125 MB compressed). A **50 MB installer is unreachable without leaving Electron** (out of scope per user). ~100 MB is achievable; state this in deploy docs. Future lever (mention only): blockmap/differential updates in `updater.ts`, which today downloads the full NSIS per update.

## Key constraints discovered (must respect)

- **Path-depth contract**: `enrollment.ts` reads `../../package.json` and `electron.ts` loads `../../src/renderer/index.html` — compiled/bundled entries must live exactly two levels below `agent/` (`out/main/`, `app/main/` OK). `files` must keep `package.json` + `src/renderer/**` at asar root.
- **jimp is eagerly `require`d by nut-js at module load** (`provider-registry.class.js` → `jimp-image-*`) — plain exclusion of jimp crashes the agent at startup. Must be stubbed via bundler alias (B2), not `!`-excluded.
- **Native modules load per-platform lazily** (libnut ternary, node-pty `prebuilds/<plat>-<arch>`, koffi `build/koffi/<triplet>`) → pruning foreign-platform packages is runtime-safe.
- **`screenshot-desktop` must stay external** (loads `./lib/win32/*.bat` via `__dirname`); **`node-screenshots` dynamic `import()` must stay external** (native).
- `updater.ts` downloads from server URL — output-dir changes don't affect it.
- `npmRebuild: false` stays (AGENTS.md: prebuilt natives only).
- Free win: node-pty prebuilds ship ~56 MB of `.pdb` debug symbols (win32-x64 + win32-arm64).

## Phase A — Fix packaging bugs

### A1. Separate tsc output from electron-builder output
- `agent/tsconfig.json` — `outDir: "./dist"` → `"./out"`.
- `agent/package.json` — `"main": "./dist/main/electron.js"` → `"./out/main/electron.js"` (depth contract preserved).
- `agent/electron-builder.yml` — **keep** `directories.output: dist` (installers stay in `agent/dist/`, matching docs); `files: dist/**` → `out/**` (with A2).
- `agent/package.json` scripts — add `"clean"` (rm `out/` + `dist/`); root `package.json` `build:agent` runs clean first.
- `.gitignore` — already ignores `agent/out/`, `agent/dist/`; add `!agent/build/` so buildResources icons can't be silently ignored.
- Grep for leftover `dist/main` references after the change.

### A2. Fix `files` — stop packing root node_modules and compiler noise
- Remove `node_modules/**` from `files` entirely — let electron-builder auto-collect production deps (it handles workspaces hoisting).
- New `files`:
  ```yaml
  files:
    - out/**
    - src/renderer/**
    - package.json
    - "!**/*.map"
    - "!**/*.d.ts"
    - "!**/*.pdb"
    - "!**/node_modules/**/README*"
    - "!**/node_modules/**/CHANGELOG*"
    - "!**/node_modules/**/*.md"
    - "!**/node_modules/**/test/**"
    - "!**/node_modules/**/tests/**"
    - "!**/node_modules/**/docs/**"
    - "!**/node_modules/node-pty/src/**"
    - "!**/node_modules/node-pty/scripts/**"
    - "!**/node_modules/node-pty/prebuilds/win32-arm64/**"
    - "!**/node_modules/node-pty/prebuilds/darwin-*/**"
    - "!**/node_modules/koffi/src/**"
    - "!**/node_modules/koffi/doc/**"
    ```
  (Keep `node-pty/deps/winpty` + `third_party` in Phase A; only drop after terminal smoke proves `prebuilds/win32-x64` copy suffices. Use separate negation lines — brace globs are unreliable in electron-builder.)
- **Hoisting is the risk**: verify `@monitour/shared` (workspace link) and every production dep lands in asar (assertions below). Fallback if collector misses hoisted packages: explicit positive per-package `files` list — never go back to `node_modules/**`.

### A3. Remove `app-builder-bin`
- Delete from `agent/package.json` `dependencies` (only referenced there; electron-builder provides its own). Run `npm install` at root to update the lockfile. **-207 MB**.

### A4. Tighten `asarUnpack`
```yaml
asarUnpack:
  - "**/*.node"
  - "**/*.dll"
  - "**/node_modules/node-pty/**/*.exe"      # winpty-agent.exe, OpenConsole.exe must spawn from disk
  - "**/node_modules/node-pty/prebuilds/**"
  - "**/node_modules/node-pty/build/**"
  - "**/node_modules/koffi/build/**"
  - "**/node_modules/node-screenshots*/**"
```
Drop blanket `**/*.exe`, `**/*.pdb`, and whole-`koffi/**` unpack. If koffi misbehaves, widen back to `**/node_modules/koffi/**` (1.9 MB).

### A5. Docs & scripts
- `agent/tsconfig.json` — add `"declarationMap": false, "sourceMap": false` (keep `composite` — root `tsc -b` needs it; `.d.ts` still emits but A2 excludes it).
- Root `package.json` `build:agent` → `npm run clean --workspace agent && npm run build --workspace agent && npm run dist --workspace agent`.
- `deploy/README.md` packaging section — compiled JS in `agent/out/`, installers in `agent/dist/`, add clean step.

**Expected after Phase A**: `app.asar` ~25–40 MB, NSIS ~110–160 MB (from 1.8 GB).

## Phase B — Size diet (~85–125 MB)

### B1. esbuild-bundle the main process
- New `agent/scripts/bundle.mjs`: bundle `src/main/electron.ts` + `src/main/index.ts` → `app/main/*.js`, `--bundle --format=esm --platform=node --target=node20`, `--outdir=app/main`.
  - `--external`: `electron`, `koffi`, `node-pty`, `node-screenshots`, `screenshot-desktop`, `@nut-tree-fork/libnut-*`, `@nut-tree-fork/default-clipboard-provider`.
  - `--alias:jimp=./scripts/jimp-stub.mjs` (B2).
- New `agent/scripts/jimp-stub.mjs` — throws on use (image APIs never called by the agent).
- Add `esbuild` to agent devDependencies.
- `agent/package.json` `"build"` → `tsc && node scripts/bundle.mjs` (tsc remains dev/typecheck emit).
- `agent/electron-builder.yml` — `extraMetadata: { main: ./app/main/electron.js }` (packaged entry = bundle; dev entry stays `out/`). `files` → `app/**`, `src/renderer/**`, `package.json`, plus explicit externals' `node_modules` dirs (`koffi`, `node-pty`, `node-screenshots*`, `screenshot-desktop`, `@nut-tree-fork/libnut-*`, `@nut-tree-fork/default-clipboard-provider`) + the A2 negations.
- Inlined in the bundle: axios, socket.io-client, node-forge, bcryptjs, jpeg-js, `@monitour/shared`, `@nut-tree-fork/nut-js` (+ its shared/provid­er-interfaces), jimp (as stub).
- Interop notes: nut-js is CJS (named-export interop via esbuild `__toESM` — smoke-test `mouse/keyboard`); `service.ts`'s non-analyzable `import('node-windows')` stays a runtime miss (existing fallback behavior).
- **Fallback (B1-alt)** if bundling fights a dep: skip bundler, keep Phase A ship-set, stub jimp via npm `overrides` — larger (~+6 MB) but zero bundler risk.

### B2. Prune jimp tree
- Handled by B1's alias. Verify `grep -c jimp` on asar listing = 0 and mouse/keyboard smoke passes (those paths never touch image APIs).

### B3. Per-platform native pruning
- New per-target configs: `agent/electron-builder.win.yml`, `.mac.yml`, `.linux.yml` (complete configs — don't rely on `extends` merge semantics). Scripts: `dist:win` / `dist:mac` / `dist:linux`.
- Each excludes foreign-platform natives (runtime-safe, verified lazy loading):
  | Artifact | win | mac | linux |
  |---|---|---|---|
  | `@nut-tree-fork/libnut-*` | win32 only | darwin only | linux only |
  | `node-pty/prebuilds/*` | win32-x64 only | darwin-x64+arm64 | confirm on linux builder (may need `build/Release`) |
  | `node-screenshots-*` | win32-x64-msvc | darwin variant | linux variant |
  | koffi `build/koffi/*` | win triplet | darwin triplets | linux triplet |
- mac builds require a macOS host (pre-existing constraint).

### B4. Size knobs
- `electronLanguages: ["en-US"]` — strips ~48 MB of Chromium locales (verify key name in electron-builder 26 schema; fallback: `afterPack` deleting locales).
- `compression: maximum` (LZMA for NSIS/AppImage).
- Keep `nsis: oneClick/perMachine` as-is (silent self-update depends on it).

### B5. Expected sizes

| Stage | Win NSIS | mac DMG | Linux AppImage |
|---|---|---|---|
| Today | ~1.8 GB | same bug | same bug |
| After Phase A | ~110–160 MB | ~120–170 MB | ~120–170 MB |
| After Phase B | **~85–125 MB** | ~95–135 MB | ~95–130 MB |
| Electron-only floor | ~85–110 MB | ~90–120 MB | ~90–120 MB |

## Implementation order

1. **Phase A (A1→A5)** — one change-set. Gate: asar assertions + Windows smoke + `tsc` green in all 4 packages.
2. **B3 per-platform pruning + B4 knobs** (low risk, independent).
3. **B1/B2 bundling** (the riskier bit, last). Gate: full smoke incl. all native consumers.

## Top risks

| Risk | Mitigation |
|---|---|
| Hoisted-workspace dep collection misses packages (esp. `@monitour/shared` symlink) | asar MUST-contain assertions every build; fallback = explicit per-package files list |
| jimp eager-loaded by nut-js → naive exclusion crashes at startup | bundle + `--alias:jimp=stub` (never plain exclusion) |
| ESM bundle × CJS natives interop | externals listed; smoke every native consumer; B1-alt fallback |
| node-pty winpty/conpty helper lookup (`build/Release` vs `prebuilds/`) | keep both copies in Phase A; drop only after terminal smoke |
| koffi `build/koffi/<triplet>/koffi.node` must exist pre-pack | assert in dist docs/pre-flight; asarUnpack `koffi/build/**` |
| Entry path-depth contract (`../../package.json`, `../../src/renderer`) | entries always at `<dir>/main/*.js` two levels below `agent/` |
