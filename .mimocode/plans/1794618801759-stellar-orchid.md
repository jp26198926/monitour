# Agent: Close-to-Tray, No Desktop Shortcut, Tray Toggle + Gated Quit

## Requirements (user-confirmed)
1. **Close = hide**: window close button / Alt+F4 hides the window; the agent process + connection + update checker keep running. Reopen via tray double-click or launching the app again (single-instance).
2. **No desktop shortcut** in the installer (Start Menu shortcut stays).
3. **"Show in System Tray" toggle** (default ON) in the **App tab** (renamed from "Updates"): tray icon with double-click → open, menu Open/Quit. **Quit paths** (tray Quit + "Quit agent" button in Service tab) require the **settings password when one is set**.

## Files & changes

### 1. `agent/src/renderer/tray-icon.png` — **create** (32×32 simple "M" mark, generated programmatically)
Note: `agent/build/` (buildResources) **does not exist** in this project — the design's `build/icon.png` source is invalid. `src/renderer/**` is already shipped via `files:` in electron-builder.yml and resolves both in dev and inside `app.asar`, so the icon lives there. No `extraResources` needed.

### 2. `agent/src/main/enrollment.ts`
- `AgentConfig` += `showInTray?: boolean` (not a secret — keep out of `OBFUSCATED_FIELDS`). Read convention `cfg?.showInTray !== false` (absent = ON, mirrors `autoUpdate`).

### 3. `agent/src/main/electron.ts` — lifecycle + tray
- Imports: `Tray, Menu, nativeImage, type NativeImage`. State: `let tray: Tray | null = null; let isQuitting = false;`
- **`showMainWindow()`**: show/restore/focus existing window, else `createWindow()` — used by `second-instance`, tray, `activate`.
- **Hide-on-close** (covers BOTH close paths):
  - `createWindow()`: `mainWindow.on('close', e => { if (!isQuitting) { e.preventDefault(); mainWindow.hide(); } })` (Alt+F4 / OS close).
  - `window-close` IPC → `mainWindow.hide()` (frameless ✕ button sends this — it never fires native `close`).
- **Single-instance** (before `whenReady`, in ALL modes incl. `--service`): `app.requestSingleInstanceLock()`; no lock → `app.quit()` and skip ALL startup (wrap `whenReady` body in `else`); `app.on('second-instance', () => showMainWindow())`.
- **Tray**: `loadTrayIcon()` — `join(__dirname, '../../src/renderer/tray-icon.png')`, fallback `process.resourcesPath/tray-icon.png`, else warn + run tray-less (never `new Tray(empty)`). `createTray()` (skip if `HEADLESS` or exists): icon resized 16×16, tooltip "Monitour Agent", menu **Open** + **Quit**, `double-click` → show (mac: `click`). `destroyTray()`. `applyTraySetting()` = `!HEADLESS && cfg?.showInTray !== false ? createTray() : destroyTray()` — called in `whenReady` and from the setter.
- **Password-gated quit**: `requestQuit()` (tray): `isPasswordSet()` → `showMainWindow()` + `webContents.send('prompt-quit-password')`; else `app.quit()`. `ipcMain.handle('quit-app', guard(() => { app.quit(); return { success: true }; }))` — `guard()` re-verifies the password in main.
- **Shutdown**: `before-quit` → `isQuitting = true` (lets the close interceptor pass — otherwise quit hangs), clear `statusTimer`, `updateChecker?.stop()`, `connection?.disconnect()`, `destroyTray()`. **`window-all-closed` stays registered as a no-op** (deleting it re-activates Electron's default quit-on-last-window — that would kill the hidden agent).
- `get-settings` += `showInTray`. New guarded IPC `set-show-in-tray(password, enabled)` → persist + `applyTraySetting()`.
- `activate` → `showMainWindow()`.

### 4. `agent/src/renderer/index.html`

### 5. `agent/src/renderer/app.js`
- `refreshSettingsView` += `showInTrayToggle.checked = s.showInTray !== false`.
- Tray toggle handler (mirror `autoUpdateToggle`): `gatePassword` → `invoke('set-show-in-tray', gate.password, enabled)`; revert checkbox on failure.
- Quit button handler: `gatePassword` → `invoke('quit-app', gate.password)`; alert on failure.
- `ipcRenderer.on('prompt-quit-password', …)`: `showPasswordPrompt` → cancel keeps agent alive → `invoke('quit-app', pwd)`.
- Password-less case: `gatePassword` returns `{ok, password:null}` → `guard()` inactive → quit proceeds.

## IPC summary
| Name | Dir | Gate | Effect |
|---|---|---|---|
| `window-close` | r→m | — | hide window |
| `set-show-in-tray` | r→m invoke | `guard` | persist + create/destroy tray |
| `quit-app` | r→m invoke | `guard` | `app.quit()` |
| `prompt-quit-password` | m→r | only when password set | password modal → `quit-app` |
| `get-settings` | r→m | — | + `showInTray` |

## Gotchas (carry into implementation)
1. Keep `window-all-closed` as a no-op handler — Electron quits by default without one.
2. `isQuitting` must gate the close interceptor or `app.quit()` hangs.
3. Two close paths (IPC `window-close` + native `close`) — both must hide.
4. Single-instance lock in HEADLESS too (a manual GUI launch next to the service would otherwise open a second connection with the same device token); lock-less instance must skip ALL startup.
5. `guard()` password is always renderer arg 0.
6. Never create the tray in `--service --hidden`.
7. Tray-off + hidden window → reopen only via relaunch (single-instance) — that's why the lock is mandatory.
8. Tray-quit with password must `showMainWindow()` first (nowhere to host the modal otherwise).

## Verification
1. `npx tsc` clean (shared/server/dashboard/agent) + `node --check src/renderer/app.js`.
2. **Close = hide**: ✕ and Alt+F4 both hide; dashboard shows the device still **online** (connection alive).
3. **Reopen**: tray double-click shows window; relaunching the app shows the existing window — no second process.
4. **Toggle**: uncheck "Show in System Tray" → icon disappears; close → relaunch reopens (single-instance), no icon. Check ON while hidden → icon appears immediately.
5. **Quit without password**: tray Quit / "Quit agent" exits immediately; device goes offline in dashboard.
6. **Quit with password**: both quit paths prompt; wrong password/cancel → agent stays alive; correct → exits.
7. **Installer**: build NSIS → no desktop shortcut; Start Menu entry remains.
8. **HEADLESS** (`--service --hidden`): no window, no tray, connection up.
9. Persistence: `showInTray:false` survives relaunch and re-enroll.
